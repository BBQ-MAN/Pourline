# 프로브 A 결과 (2026-10-28, macOS + bleak)

- 기기: TIMEMORE Dot, Model `TES017`, Firmware `v1.0.4`, Manufacturer `TIMEMORE`
- 캡처 도구: macOS CoreBluetooth(bleak 3.0.2). nRF Connect 대신 사용. MTU는 macOS가 247로 자동 협상(23 고정 불가)
- 로그: `_workspace/04_device_probeA_mac.log` (RX 14,507줄, 캡처 4회 중 실제 연결 3회(재시작2는 기기를 못 찾음). 각 캡처마다 `+초` 시각이 0부터 다시 시작한다. 경계는 `EV 캡처 재시작*` 줄)
- 로그 줄 형식: `+<경과초> RX FFF1 <hex>` / `+<경과초> TX FFF2 <hex>` / `+<경과초> EV <설명>`. 알림 하나 = 한 줄, 붙어 온 프레임은 나누지 않았다

## 원문에 없는 프레임: Notify cmd `0x04`

`A55A 01 04 0005 <5바이트> 0000`. 의미 미상.

| 직전 동작 | 받은 0x04 payload |
|-----------|-------------------|
| 앱 타이머 시작(쓰기) | `00 00000000` |
| 앱 타이머 일시정지(쓰기) | 없음(리셋 상태에서 일시정지했을 때는 `01 00000000`) |
| 앱 타이머 리셋(쓰기) | `02 00000000` 다음 `01 00000000` |

앱은 모르는 cmd를 버리고 계속 동작해야 한다.

## 확인하지 못한 항목

- C-01-4/C-01-6(oz 모드 배율): 이 기기는 버튼·화면으로 단위를 바꿀 수 없고 MVP는 0x06 쓰기를 하지 않는다. 시험하지 않았다
- C-01-9(3599 s 초과), C-01-10/11(과부하): 시험하지 않았다
- F-11·6단계(MTU 23에서 13~16바이트 이름 쓰기 분할): macOS는 MTU를 정할 수 없어 시험하지 않았다. 휴대폰 nRF Connect로 따로 해야 한다
- C-0B/C-19/C-1A: 실행하지 않았다(전원 끄기·공장 초기화·페어링 잊기)
